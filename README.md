# منصة فاطمة التعليمية • Fatima Learning Platform 🌟👑

منصة تعليمية تفاعلية مخصصة للمرحلة الابتدائية ومنهج اللغة الإنجليزية للصف الثالث (Sudan Basic Level - SMILE Book 3) بالإضافة إلى التأسيس الصوتي والتهجئة الرقمية.

## 🚀 المميزات الرئيسية
- **بوابة موحدة (Portal Hub):** انتقال فوري بين أقسام التأسيس والمنهج الدراسي وبنك الامتحانات.
- **تطبيق التأسيس الصوتي (English Phonics & Spelling):** 78 بطاقة رقمية ناطقة مدعومة بالصور والاختبارات الصوتية.
- **منهج SMILE Book 3 للصف الثالث الأساسي:** تغطية كاملة لجميع الوحدات (Units 1 - 6) مع المفردات، المحادثات، ألعاب ترتيب الكلمات (Word Builder LTR)، ولعبة أيام الأسبوع التفاعلية.
- **محرك امتحانات Test King 👑:** 5 نماذج امتحانات وزارية متدرجة (55 سؤالاً صوتياً ومصوراً) مع استخراج شهادة تفوق ملكية قابلة للطباعة والتحميل باسم الطالبة فاطمة.
- **تطبيق ويب تقدمي (PWA):** يدعم التثبيت على الهاتف والحاسوب والعمل بدون إنترنت (Offline Cache).
- **قفل الخروج للأطفال (Child Exit Lock):** حماية كاملة للشاشة ومنع خروج الطفل إلا برمز سري مخصص لولي الأمر.

## 🛠️ التقنيات المستخدمة
- HTML5 / CSS3 / JavaScript (Vanilla)
- Web Speech API (نطق إنجليزي بشري نقي)
- Service Workers & PWA Manifest
- Apache Configuration (.htaccess) لسرعة التحميل وضغط Gzip
